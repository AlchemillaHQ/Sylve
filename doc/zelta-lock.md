% zelta-lock(8) | System Manager's Manual

# NAME
**zelta lock** - lock a dataset tree for Zelta promotion workflows

# SYNOPSIS
**zelta lock** [_OPTIONS_] _endpoint_

# DESCRIPTION
The lock step is documented under **zelta-failover(8)**. It applies ordered readonly, canmount, unmount, and remount operations for a promotion workflow.

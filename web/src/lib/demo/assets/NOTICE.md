# v86 runtime assets

`seabios.bin` and `vgabios.bin` are the BIOS assets used by the
[v86](https://github.com/copy/v86) browser emulator. They were obtained from the project's
official hosted build at `https://copy.sh/v86/bios/`.

v86 is distributed under the Simplified BSD license. SeaBIOS and its VGA BIOS build retain
their upstream licenses. The guest images are fetched on demand from the public v86 image host
and are not stored in this repository.
